# ActividadConversor

#DESCRIPCION:
En este proyecto se desarrollara un aplicativo por consola  que permite realizar conversiones por medio de un menu interactivo por ello se ha divido en siete fases que son:
 1. FASE 1: CREACIÓN DE PROYECTO
 3. DISEÑO DEL MENÚ PRINCIPAL
 5. CONVERSOR DE DIVISAS
 6. CONVERSOR DE DISTANCIAS
 7. CONVERSOR DE TEMPERATURA
 8. USO DE ESTRUCTURAS DE CONTROL
 9. VALIDACIONES MINIMAS
#OBJETIVOS:
El objetivo de este proyecto es  reforzar el diseño de aplicaciones utiles con codigo reutilizables ademas de la entrada de datos
,uso de variables numéricas. operaciones matemáticas .estrucuras condicionales y organización básica dle código.
